# JS 1.6.5 Parity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `tbc-contract-go` byte-compatible with `tbc-contract` 1.6.5 for FT v3, Token HTLC, Token OrderBook, and the approved smaller parity gaps, then prove it with automated tests and TBC testnet broadcasts.

**Architecture:** A shared FT script classifier in `lib/util` supplies version metadata to all composed contracts. Protocol builders remain deterministic and network-free; online wrappers and the testnet harness compose those builders with `lib/api`. JavaScript 1.6.5 fixtures are generated once and committed without keys so Go tests can compare scripts, preimages, and transaction structure.

**Tech Stack:** Go 1.17, `github.com/LoongYearMeta/tbc-lib-go`, Go `testing`, JavaScript `tbc-contract` 1.6.5 at `19acaa0e279c39741c9957e1236b3eac9ff4154a`, TBC testnet API.

## Global Constraints

- JavaScript commit `19acaa0e279c39741c9957e1236b3eac9ff4154a` is the byte-level reference.
- TBC is always integer satoshis; FT is always raw minimum-unit `*big.Int`.
- No production transaction arithmetic uses `float64`.
- Every production behavior starts with a focused failing test.
- Preserve FT v1, FT v2, StableCoin, and current public Go APIs.
- Broadcast only to TBC testnet; no mainnet endpoint or broadcast is permitted.
- Never add or print the supplied WIF, raw private keys, or ephemeral secrets.
- Broadcast parents before children and verify every returned txid before continuing.
- Pool NFT v1 and StableCoin admin MuSig2 broadcasts are outside this plan.

```go
func FillCharLengthInFT(script *bscript.Script) (int, error) {
	chunks := script.Chunks()
	if len(chunks) < 5 {
		return 0, fmt.Errorf("FT code has %d chunks; need at least 5", len(chunks))
	}
	op := int(chunks[len(chunks)-5].OpcodeNum)
	switch op {
	case 95:
		return 1, nil
	case 2:
		return 2, nil
	default:
		return op, nil
	}
}
```

Classification rules:

```go
switch len(script.Bytes()) {
case 1564:

case 2012:

case 1884:

	if err != nil {
		return FTScriptInfo{}, err
	}
	if fill == 1 || fill == 2 {
		return FTScriptInfo{Version: FTVersion3}, nil
	}
	return FTScriptInfo{Version: FTVersion2}, nil
default:
	return FTScriptInfo{}, fmt.Errorf("unsupported FT code length %d", len(script.Bytes()))
```
